# 🛡️ SpamShield AI

A machine learning web application that detects whether a text message is Spam or Not Spam.

## 🚀 Features

- Spam message classification
- TF-IDF text vectorization
- Logistic Regression machine learning model
- Spam probability
- Interactive Streamlit interface
- Ready for cloud deployment

## 🧠 Machine Learning

The project uses:

- TF-IDF Vectorization
- Logistic Regression
- Scikit-learn

The model was trained using the SMS Spam Collection dataset.

## 📊 Model Performance

Test accuracy:

96.77%

## 🏗️ Architecture

↓
